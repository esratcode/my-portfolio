PROJECT DETAILS

Bazar Dor — Market Price Tracker

About the Project

Bazar Dor is a web application designed to help people in Bangladesh explore the prices of essential goods and compare current prices with previous prices.

Technologies Used

Next.js, React, JavaScript, Tailwind CSS

Key Features

Product price display, category filtering, product details, and price comparison.

Challenges

Working with API data, creating dynamic product pages, and building a responsive interface are important learning experiences in this project.

Future Improvements

I plan to improve the design and add more useful price-tracking features.
