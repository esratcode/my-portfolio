Bazar Dor — Market Price Tracker

Explore my project, technologies, features, and development journey.

About the Project

Bazar Dor is a market price tracking website designed to help users explore the prices of essential goods and compare current prices with previous prices. It aims to make everyday market price information easier to access.

Technologies Used

Next.js, React, JavaScript, Tailwind CSS, REST API Integration

Key Features

Product price display, category-based browsing, price rise and fall information, dynamic product details, and a responsive interface.

Challenges Faced

Fetching product and category data from an API, displaying price changes clearly, and organizing product information into an easy-to-use interface were important development challenges.

Future Improvements

I plan to improve product filtering, complete authentication features, enhance price comparison, and introduce additional features to make the website more useful.
